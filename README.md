# 🚀 SeederControlTerminal (Инженерный пульт АСКУЭ)

![Интерфейс программы](Terminal.png)

Кроссплатформенный автономный эхо-терминал для отладки сетевого JSON/TCP взаимодействия систем промышленной автоматизации. Разработан на базе **Avalonia UI** и **ReactiveUI** с прицелом на встраиваемые системы под управлением Windows и Linux (.NET 9).

## 🛠️ Стек технологий:
* **C# 13 / .NET 9**
* **Avalonia UI 11+** (XAML)
* **ReactiveUI** (Реактивные команды `CreateFromTask` и валидация `WhenAnyValue`)
* **System.Text.Json** (Сериализация пакетов DTO)
